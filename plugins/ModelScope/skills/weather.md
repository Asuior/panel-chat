# 天气查询技能

## 目标
当用户的请求涉及"查天气 / 天气怎么样 / 今天热不热"等内容时,启用本技能。

## 执行规范
1. 先从用户消息里提取要查询的城市。
2. 当前实现仅支持北京,若用户问其他城市,礼貌告知暂只支持北京。
3. 调用 `get_weather` 工具获取天气数据。
4. 用一句话回报结果,格式为:`【城市】今天【天气】,气温【温度】`。

## 注意事项
- 不要编造工具返回值之外的数据。
- 语气友好、简洁。
