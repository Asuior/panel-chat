# 天气查询技能

## 目标
当用户的请求涉及"查天气 / 天气怎么样 / 今天热不热"等内容时,启用本技能。

## 执行规范
1. 调用 `get_weather` 工具获取天气数据。
2. 从Open-Meteo格式返回数据中提取用户需要的信息进行回答。
3. 如用户需要的信息在工具返回结果中不存在，则如实回答不知道。

## 注意事项
- 不要编造工具返回值之外的数据。
- 语气友好、简洁。
